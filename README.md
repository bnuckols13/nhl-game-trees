# NHL Game Trees — desk library

Private working papers of the DFS desk. Not published advice, not a
tip sheet, and nothing here enters a contest.

A growing library of game trees, organised by sport and slate:

- `/` — library home (sports index)
- `/nhl/` — NHL slates and standing pages, including the measured
  history of how NHL GPPs are won
- `/nhl/2026-11-03/` — the Tuesday, November 3, 2026 Main slate:
  slate index, field notes, and one tree per game

Site convention: see STRUCTURE.md. Plain static HTML/CSS, no build
step. Start at index.html.
