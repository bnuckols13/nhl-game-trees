How a game page is built. Level 1 is the game itself: how many goals, priced as scripts, never as a single score. Level 2 is capture: under each script, which unit actually holds the points, measured from shared goals in the play-by-play. Level 3 is the leaves: the lineups each branch calls for, tiered core, secondary and convex, with a convex leaf never built naked. Every number is labelled measured, market or modelled, and each page carries its own trust limits.
